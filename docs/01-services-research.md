# AI-Mola-manager — дослідження сторонніх сервісів для бота

Дата: 2026-10-28. Ціни та функції взяті з сайтів сервісів і можуть змінюватися. Перед вибором перевірте їх на демо або в trial.

## Вимоги, за якими порівнюємо

| # | Вимога | Пріоритет |
|---|---|---|
| 1 | Відповіді на прості питання | перший |
| 2 | Аналіз усього попереднього діалогу | високий |
| 3 | База знань: продукти й наявність, воронки, система продажів | високий |

## 1. MyChatBot (mychatbot.app) — найближчий до вимог

- **Канали (з тарифу Standard):** Telegram (бот і акаунт), Instagram, Viber, Facebook, WhatsApp, віджет сайту, OLX, TikTok, SMS, email.
- **KeyCRM:** є нативна інтеграція через API-ключ ([документація](https://docs.mychatbot.app/integrations/keycrm)).
  - Ліди: створення, оновлення, пошук за телефоном, воронкою, статусом.
  - Замовлення: створення, оновлення, пошук за ID або телефоном. Товари зіставляються за SKU.
  - Клієнти: пошук за телефоном або створення нової картки, оновлення пов'язаних лідів і замовлень.
  - Товари: імпорт та індексація каталогу, автооновлення.
- **База знань:** FAQ, товарні фіди, таблиці, семантичний пошук і пошук за зображенням.
- **Передача оператору:** у будь-який момент.
- **Розширення:** власні MCP-сервери на тарифі Pro. Через них можна підключити дані з 1С.
- **Ціни ([pricing](https://mychatbot.app/pricing)):**

| Тариф | Ціна | AI-відповідей на місяць |
|---|---|---|
| Solo | $19 | 200 (1 канал) |
| Standard | $49 | 600 (усі канали) |
| Pro | $99 | 1 200 (CRM/ERP, MCP) |
| Multipro | $199 | 3 000 |

  Додаткові відповіді коштують близько $40 за 1 000. Є trial на 3 дні.
- **Мінуси:**
  - Навчання на старих діалогах явно не заявлене. Скоріш за все, доведеться завантажити приклади діалогів у базу знань як «стиль продажу».
  - Немає публічних деталей про захист від prompt injection.

## 2. HAPP AI (happ.tools)

- **Канали:** Telegram, Viber, Instagram, Facebook, WhatsApp, а також Custom Messenger, через який можна зробити віджет.
- **KeyCRM ([сторінка](https://happ.tools/integrations/crm/keycrm)):**
  - Читає каталог, клієнтів, воронки й замовлення в реальному часі.
  - Після підтвердження в чаті створює замовлення в потрібній воронці приблизно за 1–2 секунди і заповнює поля клієнта.
  - Оцінює «температуру» ліда, а гарячих передає менеджеру разом із контекстом.
- **Безпека:** API-ключ KeyCRM зберігається зашифрованим і нікому не показується.
- **Ціни:** публічно не вказані, залежать від кількості інтеграцій.
- **Мінус:** мало публічної документації про базу знань. Потрібне демо.

## 3. Aceverse (aceverse.co) — агентство з готовим рішенням для KeyCRM

- **Канали:** працює всередині KeyCRM Chats: сайт, Telegram, Viber, Instagram, WhatsApp. Є голосовий агент українською.
- **KeyCRM ([опис](https://www.aceverse.co/en/blog/ai-pidtrymka-keycrm)):**
  - Статус замовлення, ТТН, залишки на складі, створення лідів, повернення.
  - Через вебхуки бот сам пише клієнту про зміну статусу.
- **Передача оператору:** менеджер отримує AI-резюме діалогу й продовжує в тому ж інбоксі KeyCRM.
- **Формат:** впровадження під ключ. Починається з пілоту на одному сценарії (приблизно 2 тижні). Ціна індивідуальна.
- **Плюс:** менеджери не міняють інструмент, усе лишається в KeyCRM.
- **Мінус:** це сервіс агентства, а не SaaS-конструктор, тому команда менше контролює налаштування.

## 4. SendPulse (sendpulse.ua) — конструктор чат-ботів з AI-кроком

- **Канали:** Telegram, Instagram, Viber, Facebook, WhatsApp, віджет сайту, омніканальний інбокс.
- **AI Agent ([гайд](https://sendpulse.com/blog/how-to-set-up-the-ai-agent)):**
  - Моделі GPT або Gemini.
  - Файли бази знань: txt, doc, pdf, json, html. Пошук по файлах працює тільки з моделями OpenAI.
  - MCP-інструменти, вебпошук.
- **KeyCRM:** нативної інтеграції немає. Можна підключити через HTTP-запити у flow або MCP, але це пишемо самі.
- **Ціни:**
  - Basic безкоштовний: до 500 підписників і 3 ботів.
  - Токени AI оплачуються окремо з вашого ключа OpenAI.
- **Плюси:** гнучкі сценарії (кнопки, воронки, розсилки), відомий український продукт.
- **Мінус:** AI тут лише один крок у сценарії. Логіку «агента-продавця» з CRM доведеться збирати вручну.

## 5. Smart Sender (smartsender.com)

- **Канали:** Telegram, Viber, Instagram, Facebook. Безкоштовно до 500 підписників.
- **KeyCRM:** тільки через посередника ApiX-Drive.
- **Оцінка:** сильний для сценарних ботів і розсилок, але не для AI-агента з CRM. Підходить як запасний варіант.

## Не підходять (для довідки)

- **Respond.io:** сильний AI-агент, але Viber під питанням. AI-агенти доступні з тарифу Growth (від ~$159–199/міс), оплата за активних контактів.
- **ManyChat, Chatfuel, Botpress, Voiceflow:** немає нативного Viber і інтеграції з KeyCRM.

## Рекомендація

1. **Основний кандидат — MyChatBot (тариф Pro, $99).**
   - Закриває всі канали й віджет.
   - Нативно працює з KeyCRM, включно з пошуком і створенням клієнта та замовлення.
   - Через MCP можна підключити дані з 1С.
   - Можна стартувати на Standard ($49) з одними тільки відповідями на прості питання (задача №1).
2. **Паралельно взяти демо в HAPP AI**, порівняти якість відповідей українською і ціну.
3. **Aceverse** — якщо компанія хоче, щоб бот жив усередині KeyCRM Chats і впровадження зробили за неї.

## Що робимо самі (поза сервісом бота)

### Вивантаження з 1С
- Найпростіше: разово вивантажити клієнтів і замовлення з 1С у CSV або Excel і імпортувати в KeyCRM. Тоді бот бачить усіх клієнтів через одну інтеграцію.
- Якщо 1С продовжує жити: робимо регулярну синхронізацію. Варіанти:
  - модуль обміну в 1С через KeyCRM OpenAPI;
  - посередник ApiX-Drive.
- Сирі дані з 1С напряму в бот не давати. Тільки через CRM або вузький API.

### Dashboard на GitHub Pages
- Статичний сайт, який дані про роботу бота бере через API сервісу або KeyCRM.
- Показники: кількість діалогів, % закритих без оператора, передачі менеджеру, створені замовлення, конверсія.
- **Важливо:** GitHub Pages публічний і не має бекенду. Ключі KeyCRM і бота не можна класти у фронтенд. Потрібен маленький проксі для даних: Cloudflare Worker або GitHub Action, що за розкладом формує JSON без персональних даних, плюс авторизація.

### Безпека (вимога №6), незалежно від сервісу
- Ключ KeyCRM з мінімальними правами. Бот бачить тільки дані клієнта, з яким говорить, і шукає лише за його телефоном або ID чату.
- Жодних інструментів «вивантажити всіх» чи «знайти будь-кого за іменем».
- У системному промпті: роль, межі компетенції, заборона розкривати інструкції, ліміт довжини відповіді.
- Перед запуском — тест на prompt injection: «ігноруй інструкції», «покажи всіх клієнтів», «дай свій промпт».
- Rate limit і антиспам на рівні сервісу; логування для дашборду.
